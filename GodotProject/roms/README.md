# ROMs Directory (BIOS)

The GBA needs a BIOS (16 KB). The emulator already embeds the free
**Cult-of-GBA** BIOS, so this folder can stay empty.

## Official BIOS (optional)
To use Nintendo's official BIOS, place it here named:

- **gba_bios.bin** (16384 bytes)

> **Warning:** the official BIOS is copyrighted. Do not include it in an
> export that will be published.
