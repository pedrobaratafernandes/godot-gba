# Games Directory

Put your Game Boy Advance games here.

## Supported formats
- **.gba** (ROM)
- **.zip** (a zip containing a .gba)

The **Launcher** lists every game in this folder automatically.
For a preview image, add a `.png` (or `.jpg`) with the same name as the game
(e.g. `my-game.gba` + `my-game.png`).

Games in this folder are also tested by `cargo test --release`.

## Where to find legal games
- Homebrew on [gbadev.net](https://gbadev.net/) and [itch.io](https://itch.io/games/tag-gameboy-advance)
